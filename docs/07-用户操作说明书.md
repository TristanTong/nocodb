# 用户操作说明书

| 项 | 内容 |
|----|------|
| 产品 | mlnocodb（基于 NocoDB） |
| 文档版本 | v0.1.0 |
| 推荐访问地址 | http://localhost:6100 |
| 源码热更新（改 UI） | http://localhost:6110 |

## 1. 使用前准备

1. 向管理员索取账号（邮箱/密码）。
2. 确认可访问前端地址（开发环境一般为 `http://localhost:6100`）。
3. 建议使用 Chrome / Edge 最新版。

> 说明：`http://localhost:6080/dashboard` 也可打开界面，但是服务器内置静态页面，功能界面可能与 6100 略有差异。日常请用 **6100**（生产构建，打开目标 ≤3s）。改前端源码请用 **6110**。

## 2. 登录与退出

1. 打开前端地址，进入登录页。
2. 输入邮箱与密码，登录。
3. 右上角/侧栏用户菜单可退出登录。

若提示无权限或密码错误，联系管理员重置。

## 3. 工作区与 Base

- **Base**：一组表与视图的集合（类似一个「数据库应用」）。
- 登录后在列表中选择 Base 进入。
- 有权限时可创建新 Base、邀请成员（视部署配置而定）。

## 4. 表与字段

### 4.1 打开表

在左侧表列表点击表名，中央为当前视图（默认网格）。

### 4.2 常见字段类型

单行文本、长文本、数字、单选/多选、日期、附件、关联（Links）、公式等。

有「编辑表结构」权限时，可通过字段菜单新增/修改/删除字段。**连接外部只读源时，删改表结构可能受限。**

## 5. 网格视图操作

| 操作 | 方法 |
|------|------|
| 新增行 | 底部/工具栏「新增」 |
| 编辑 | 单击单元格编辑后保存 |
| 删除 | 选中行 → 删除 |
| 排序 | 字段菜单或排序面板 |
| 筛选 | 筛选面板添加条件 |
| 隐藏列 | 字段显示设置 |

## 6. 其他视图

在视图切换处可创建或切换：

- **表单**：对外收集录入
- **看板**：按单选字段分列
- **画廊**：卡片式
- **日历**：按日期字段

## 7. 外部数据源（管理员）

适用于把已有 PostgreSQL / 海量库挂到当前 Base。

1. 进入 Base 的 **数据源 / Data Source** 设置页。  
   示例路径形态：`#/nc/<baseId>?page=data-source`
2. 选择添加数据源 → 类型选 **PostgreSQL**（海量库亦选此项）。
3. 填写：

| 项 | 示例 |
|----|------|
| Host | 192.168.100.99 |
| Port | 5432 |
| User | sa |
| Password | （管理员提供） |
| Database | metabase_rpt |
| Schema | 如 dbo |

4. 测试连接 → 保存并同步。
5. 同步成功后，在表列表中选择要暴露的业务表。

**失败排查：**

- 网络/防火墙不通
- 账号密码或库名错误
- 若出现 `UNNEST` / `syntax error at or near "."`，需确认服务端已升级兼容补丁

## 8. API 与 Token（可选）

1. 在账号/Base 设置中创建 API Token（视权限）。
2. 请求头携带 Token 调用 REST API。
3. 详情见产品内 Swagger/文档入口。

## 9. 注意事项

1. 生产数据请谨慎批量删除。
2. 与他人共用 Base 时注意权限与锁定视图。
3. 外挂业务库的写入会直接影响业务系统，操作前确认环境。
4. 版本信息可在侧栏 **Version** 查看，应与服务器版本一致。
