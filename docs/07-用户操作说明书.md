# 用户操作说明书

| 项 | 内容 |
|----|------|
| 产品 | mlnocodb（基于 NocoDB） |
| 文档版本 | **v0.1.3** |
| 推荐访问地址 | http://localhost:6100 |
| 源码热更新（改 UI） | http://localhost:6110 |

## 1. 使用前准备

1. 向管理员索取账号（邮箱/密码）。
2. 确认可访问前端地址（开发环境一般为 `http://localhost:6100`）。
3. 建议使用 Chrome / Edge 最新版。

> 说明：`http://localhost:6080/dashboard` 也可打开界面，但是服务器内置静态页面，功能界面可能与 6100 略有差异。日常请用 **6100**（生产构建，打开目标 ≤3s）。改前端源码请用 **6110**。

## 2. 登录与退出

1. 打开前端地址，进入登录页。
2. 输入邮箱与密码，登录。
3. 右上角/侧栏用户菜单可退出登录。

若提示无权限或密码错误，联系管理员重置。

## 3. 工作区与 Base

- **Base**：一组表与视图的集合（类似一个「数据库应用」）。
- 登录后在列表中选择 Base 进入。
- 有权限时可创建新 Base、邀请成员（视部署配置而定）。

## 4. 表与字段

### 4.1 打开表

在左侧表列表点击表名，中央为当前视图（默认网格）。

### 4.2 常见字段类型

单行文本、长文本、数字、单选/多选、日期、附件、关联（Links）、公式等。

有「编辑表结构」权限时，可通过字段菜单新增/修改/删除字段。**连接外部源且开启「禁止改结构」时，无法在 NocoDB 内新建表/加列。**

## 5. 网格视图操作

| 操作 | 方法 |
|------|------|
| 新增行 | 底部/工具栏「新增」 |
| 编辑 | 单击单元格编辑后保存 |
| 删除 | 选中行 → 删除 |
| 排序 | 字段菜单或排序面板 |
| 筛选 | 筛选面板添加条件 |
| 隐藏列 | 字段显示设置 |

> 外部业务库的写入会直接影响业务系统；请优先在隔离测试表上验证。

## 6. 其他视图

在视图切换处可创建或切换：

- **表单**：对外收集录入
- **看板**：按单选字段分列
- **画廊**：卡片式
- **日历**：按日期字段

## 7. 外部数据源（管理员）

适用于把已有 **PostgreSQL / 海量库 / SQL Server** 挂到当前 Base。

1. 进入 Base 的 **数据源 / Data Source** 设置页。  
   示例路径形态：`#/nc/<baseId>?page=data-source`
2. 选择添加数据源 → 按库类型选择：
   - **PostgreSQL**（海量/Vastbase 亦选此项）
   - **SQL Server**（Microsoft SQL Server / Azure SQL）
3. 填写连接信息：

**PostgreSQL / 海量示例：**

| 项 | 示例 |
|----|------|
| Host | 192.168.100.99 |
| Port | 5432 |
| User | sa |
| Password | （管理员提供） |
| Database | metabase_rpt |
| Schema | 如 `public` / 业务 schema |

**SQL Server 示例：**

| 项 | 示例 |
|----|------|
| Host | 192.168.1.11 |
| Port | `1433`（或实例自定义端口，如 `5678`） |
| User | SQL 登录名（本期不支持 Windows 集成认证） |
| Password | （管理员提供） |
| Database | 如 `Metabase_ODS` |
| Schema / searchPath | 业务 schema，如 `UFDATA`（**不一定是 `dbo`**） |
| Encrypt / 信任证书 | 内网常见：关闭强制加密或开启「信任服务器证书」 |

4. 测试连接 → 保存并同步。
5. 同步成功后，在表列表中选择要暴露的业务表；可按权限做网格读写。

### 7.1 SQL Server 使用注意

| 主题 | 说明 |
|------|------|
| 禁止改结构 | 默认开启时只能同步已有表与读写数据；新建表/加列/建外键 Links 需管理员关闭该限制 |
| 禁止写数据 | 开启后网格无法新增/修改/删除 |
| 公式 | 可用：`LEN`、`TRIM`、`IF`、`NOW` 等；UI 禁用：`REGEX_*`、`ARRAY*`、`DATEADD`、`VALUE`、校验和类 |
| Links | Has-Many / Belongs-To 依赖库内 FK（需允许改结构）；跨 schema 关系本期不保证 |
| 非 dbo | Schema 填错会导致同步 0 表；请与 DBA 确认真实业务 schema |

### 7.2 失败排查

- 网络/防火墙不通（SQL Server 默认端口 `1433`）
- 账号密码或库名错误；SQL Server 是否允许 SQL 登录
- Schema / searchPath 填错
- 服务端提示缺少 `mssql` 模块 → 联系运维重建含驱动的镜像
- 海量源出现 `UNNEST` / `syntax error at or near "."` → 确认已部署兼容补丁

## 8. API 与 Token（可选）

1. 在账号/Base 设置中创建 API Token（视权限）。
2. 请求头携带 Token 调用 REST API。
3. 详情见产品内 Swagger/文档入口。

## 9. 注意事项

1. 生产数据请谨慎批量删除。
2. 与他人共用 Base 时注意权限与锁定视图。
3. 外挂业务库的写入会直接影响业务系统，操作前确认环境。
4. 版本信息可在侧栏 **Version** 查看，应与服务器版本一致。
5. 侧栏不再展示 NocoDB Cloud / 礼品类商业推广入口（本仓库定制）。
