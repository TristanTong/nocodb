## 1. 系统上下文

系统为无代码数据平台：用户通过浏览器操作，后端访问 Meta 库与外部数据源，对外暴露 REST API。

**外部系统：**

- PostgreSQL Meta（如 `mlnoco`）
- 业务 PostgreSQL / 海量 Vastbase / MySQL 等
- （可选）对象存储、邮件、Redis（高级能力）

## 3. 核心数据流

### 3.1 登录与会话

1. 前端提交凭证 → `/api/v1/auth/user/signin`（或等价接口）。
2. 后端校验 Meta 中用户 → 签发 JWT。
3. 后续请求携带 Token；`/api/v1/auth/user/me` 返回角色信息。

### 3.2 添加外部数据源

1. UI 录入主机、端口、账号、库名、类型（PostgreSQL / **SQL Server** 等）。
2. Backend 测试连接。
3. 持久化 Source 配置到 Meta（加密字段按上游逻辑）。
4. **Introspect**：表/列/主键/索引/外键（PG：`relationListAll`；MSSQL：`MssqlClient` 系统视图）。
5. 生成 Base 内表模型与字段元数据，供网格使用。
6. MSSQL 注意：`searchPath` 决定 schema；默认 `is_schema_readonly` 禁止 DDL；公式走 `functionMappings/mssql`。

### 3.3 网格读数

1. UI 请求视图数据 API。
2. Backend 根据 Source 取得连接配置。
3. 通过对应 SqlClient 查询业务库并做类型映射后返回。

## 4. 接口设计（摘要）

| 类别 | 示例 | 说明 |
|------|------|------|
| 健康 | `GET /api/v1/health` | 存活探测 |
| 版本 | `GET /api/v1/version` | `currentVersion` / `releaseVersion` |
| 信息 | `GET /api/v2/meta/nocodb/info` | 含 `version`、功能开关 |
| Meta | `/api/v1/db/meta/...`、`/api/v2/meta/...` | Base/表/视图等 |
| 数据 | `/api/v1/db/data/...`、`/api/v2/...`、`/api/v3/data/...` | 记录 CRUD |

完整 OpenAPI/Swagger 可在登录后由 Base 维度导出（上游能力）。

## 5. 数据模型（Meta 关键表）

| 表（示例） | 用途 |
|------------|------|
| `nc_users_v2` | 用户 |
| `nc_bases_v2` | Base/项目 |
| `nc_sources_v2` | 数据源 |
| `nc_models_v2` | 表模型 |
| `nc_columns_v2` | 字段 |
| `nc_views_v2` 等 | 视图及相关 |

业务表结构由外部库决定，Meta 仅保存映射与 UI 配置。

## 6. 安全设计

| 项 | 设计 |
|----|------|
| 认证 | JWT；可选 SSO（视配置） |
| 授权 | 角色：如 creator/super、Base 级权限 |
| 机密 | `NC_DB`、数据源密码不入库明文到 Git |
| CORS | 开发态 Frontend 跨域访问 Backend |
| SQL | 参数化查询；introspect 使用系统目录 |

## 7. 配置项（系统级）

| 变量 | 含义 | 本环境示例 |
|------|------|------------|
| `NC_DB` | Meta 连接 | `pg://192.168.100.89:5432?u=postgres&p=...&d=mlnoco` |
| `NC_DISABLE_TELE` | 关闭遥测 | `true` |
| `NODE_ENV` | 环境 | `development` |
| `NUXT_PUBLIC_NC_BACKEND_URL` | 前端 API 根 | `http://localhost:6080` |
| `PORT` / `NC_PORT` | 后端端口 | 默认开发 6080 |

配置文件建议：`packages/nocodb/.env`（已 ignore）。

## 8. 异常与降级

| 场景 | 行为 |
|------|------|
| Meta 不可达 | 服务启动失败或 API 5xx |
| 外部源连接失败 | 添加数据源失败提示 |
| Introspect SQL 不兼容 | 需驱动层兼容改造（见详细设计） |
| 6080 与 6100 UI 差异 | 属双入口设计；开发以 6100 为准 |

## 9. 接口约定与版本

- 应用版本：`packages/nocodb/package.json` → `0.301.2`
- 发布标签：仓库 tag（如 `v0.1.0`）表示本二次开发里程碑，不等于上游版本号
- 分支命名可能含目标上游版本（如 `0.301.3`），以 `package.json` 为准
